# WOOD-BOOSTER AI USER INTERFACE SYSTEM


## Tarkoitus

Tämä dokumentti määrittää miten käyttäjä toimii Wood-Booster AI Brainin kanssa.


Käyttöliittymän tarkoitus ei ole vain näyttää tietoa.
