# WOOD-BOOSTER AI DATA ARCHITECTURE SYSTEM


## Tarkoitus

Tämä dokumentti määrittää miten Wood-Booster AI Brain järjestää, tallentaa ja käyttää tietoa.


Hyvä AI ei tarvitse kaikkea tietoa.

Se tarvitsee oikean tiedon oikeassa paikassa.


---

# PERUSPERIAATE


Tieto tarvitsee rakenteen.


Jokaisella tiedolla pitää olla:


- tarkoitus
- sijainti
- yhteys muuhun tietoon


---

# TIETOKERROKSET


Wood-Booster AI käyttää seuraavia tietokerroksia:


## 1. SYSTEM DATA


Korkein taso.


Sisältää:


- identiteetin
- arvot
- toimintaperiaatteet
- turvallisuussäännöt


Tämä tieto muuttuu harvoin.


---

## 2. KNOWLEDGE DATA


Asiantuntijatieto.


Sisältää:


- puumateriaalit
- valmistustekniikat
- liiketoiminta
- suunnittelu
- markkinointi


Tämä kasvattaa osaamista.


---

## 3. MEMORY DATA


Henkilökohtainen ja kokemuksellinen tieto.


Sisältää:


- käyttäjän tavoitteet
- tärkeät mieltymykset
- opitut asiat


---

## 4. PROJECT DATA


Projektikohtainen tieto.


Sisältää:


- asiakkaat
- tuotteet
- työvaiheet
- materiaalit
- kustannukset
- dokumentit


---

## 5. DECISION DATA


Päätöshistoria.


Sisältää:


- tehdyt päätökset
- perustelut
- seuraukset
- opit


---

6. Keskustelun hetkellinen tieto

## Tilapäinen tieto

# TIETOTURVA


Kaikki tieto ei kuulu kaikille agenteille.


Agentti saa vain tarvitsemansa tiedon.


Esimerkiksi:


Finance Agent ei tarvitse kaikkia materiaalitietoja.


Material Agent ei tarvitse asiakassopimuksia.
