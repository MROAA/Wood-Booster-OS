WOOD-BOOSTER AI BRAIN
KNOWLEDGE ARCHITECTURE

Version: 1.0
Status: Active
Priority: High

PURPOSE

This document defines how information is organized inside the Wood-Booster AI Brain.

The goal is to keep knowledge clear, searchable, trustworthy and useful as the system grows.

The AI Brain should not become a random collection of files.

Every document must have a purpose, a location and a known level of importance.

--------------------------------------------------

THE KNOWLEDGE LAYERS

1. CONSTITUTION

Contains the most stable principles of Wood-Booster.

Examples:

- Mission
- Values
- Philosophy
- Non-negotiable principles
- Long-term direction
- Human-first principle
- Role of AI

Use this layer to answer:

Who are we?
What do we believe?
What must never be compromised?

These documents change rarely.

--------------------------------------------------

2. PLAYBOOKS

Contains practical operating instructions.

Examples:

- How to start a project
- How to prepare a quotation
- How to inspect quality
- How to publish a WordPress article
- How to document lessons learned
- How to handle customer complaints

Use this layer to answer:

How do we do this?

Playbooks should improve whenever experience reveals a better method.

--------------------------------------------------

3. KNOWLEDGE

Contains facts, references and technical information.

Examples:

- Wood species
- Epoxy systems
- Finishing products
- Joinery methods
- Machines
- Tools
- Software
- Suppliers
- Material properties

Use this layer to answer:

What do we know about this subject?

Knowledge should be updated when better evidence becomes available.

--------------------------------------------------

4. THINKING

Contains reasoning frameworks.

Examples:

- First Principles Thinking
- Systems Thinking
- Root Cause Analysis
- Risk Analysis
- Decision Matrix
- Opportunity Cost
- Trade-off Analysis
- Constraint Thinking

Use this layer to answer:

How should we analyze this?

Thinking documents guide the quality of decisions.

--------------------------------------------------

5. BEHAVIOR

Contains rules for how the AI communicates and works with people.

Examples:

- How to answer
- How to ask questions
- How to handle uncertainty
- How to disagree respectfully
- When to request human approval
- When to create new knowledge

Use this layer to answer:

How should the AI behave?

--------------------------------------------------

6. MEMORY

Contains changing information about the present and recent past.

Examples:

- Active projects
- Customers
- Meetings
- Notes
- Conversations
- Current priorities
- Open decisions

Use this layer to answer:

What is happening now?
What has happened recently?

Memory changes frequently.

--------------------------------------------------

7. WISDOM

Contains lessons learned from experience.

Examples:

- What worked
- What failed
- Unexpected outcomes
- Repeated patterns
- Improvements discovered
- Mistakes that should not be repeated

Use this layer to answer:

What have we learned from experience?

Wisdom should influence future projects and Playbooks.

--------------------------------------------------

8. RESEARCH

Contains external material that may support future learning.

Examples:

- Articles
- Studies
- Patents
- Competitor observations
- Product manuals
- Market research
- Experimental notes

Use this layer to answer:

What external evidence or inspiration exists?

Research is not automatically trusted.

It must be evaluated before becoming Knowledge or Wisdom.

--------------------------------------------------

DOCUMENT RULES

Every document should have:

- A clear title
- One primary purpose
- One primary category
- A known source
- A confidence level
- A priority level
- A status
- A last updated date
- Useful tags

Avoid combining unrelated topics in one file.

Prefer several focused documents over one enormous document.

--------------------------------------------------

SOURCE OF TRUTH

Files inside:

server/ai-knowledge/

are the long-term source of truth.

The database is the searchable index used by the AI.

The file is the original.

The database is the working memory.

If they conflict, the file should be reviewed and re-imported.

--------------------------------------------------

SEARCH PRIORITY

When several documents are relevant, prefer:

1. Active Constitution
2. Active Playbooks
3. High-priority Knowledge
4. Relevant Wisdom
5. Current Memory
6. Evaluated Research
7. General model knowledge

Always-use documents should be considered before ordinary documents.

--------------------------------------------------

CONFLICT HANDLING

If two documents disagree:

1. Prefer the higher-priority document.
2. Prefer the newer verified document.
3. Prefer direct company experience over unsupported assumptions.
4. Explain the conflict to the user.
5. Request human review when the conflict affects safety, quality, money or reputation.

Never silently choose between important conflicting sources.

--------------------------------------------------

KNOWLEDGE LIFECYCLE

Every document moves through a lifecycle:

Draft

↓

Review

↓

Approved

↓

Active

↓

Updated

↓

Archived

Archived knowledge remains available for history, but should not guide current decisions unless explicitly requested.

--------------------------------------------------

WHEN NEW KNOWLEDGE IS CREATED

Ask:

What category does this belong to?

Is it fact, instruction, memory, wisdom or research?

How reliable is it?

Should it always be used?

Does it replace older information?

Should another document be updated?

--------------------------------------------------

QUALITY STANDARD

Good knowledge is:

Clear

Focused

Traceable

Current

Useful

Testable

Easy to update

Knowledge that cannot be understood or found is not yet useful knowledge.

--------------------------------------------------

FINAL PRINCIPLE

The Wood-Booster AI Brain should become more organized as it grows, not more confusing.

Every new document must strengthen the whole system.
