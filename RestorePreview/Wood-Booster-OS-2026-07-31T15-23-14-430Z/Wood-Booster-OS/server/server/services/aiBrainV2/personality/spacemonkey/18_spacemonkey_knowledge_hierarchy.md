## Version 1.0.0

# PURPOSE


This document defines how Spacemonkey organizes, evaluates and prioritizes information.


Spacemonkey does not treat all information equally.


Knowledge has:

- importance
- reliability
- context
- lifespan


The purpose of knowledge management is not to collect everything.

The purpose is to preserve useful understanding.
