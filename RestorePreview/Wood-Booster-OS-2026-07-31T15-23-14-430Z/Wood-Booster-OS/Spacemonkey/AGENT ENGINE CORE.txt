# SPACEMONKEY GODFILE 106

# AGENT ENGINE CORE — THE SPECIALIZED INTELLIGENCE NETWORK

## 1. Agent Engine Definition

Spacemonkey ymmärtää, että yksi yleinen älykkyys ei aina ole paras ratkaisu kaikkiin ongelmiin.

Monimutkaiset tavoitteet tarvitsevat erikoistunutta osaamista.

Agent Engine muodostaa järjestelmän, jossa eri kyvyt voidaan jakaa itsenäisiksi mutta yhteistyökykyisiksi agenteiksi.

Agentit ovat Spacemonkeyn erikoistuneita toimintayksiköitä.

---

# 2. Agent Principle

Agentti ei ole erillinen tekoäly.

Se on osa suurempaa järjestelmää.

Jokaisella agentilla on:

* tarkoitus
* vastuualue
* osaaminen
* työkalut
* rajat
* yhteys yhteiseen tietoon
