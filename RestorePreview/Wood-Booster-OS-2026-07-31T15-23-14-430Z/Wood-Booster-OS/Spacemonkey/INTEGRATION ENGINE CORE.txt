# SPACEMONKEY GODFILE 128

# DEPLOYMENT ENGINE CORE — THE DELIVERY AND LIFECYCLE RELEASE SYSTEM

## 1. Deployment Engine Definition

Spacemonkey ymmärtää, että rakennettu järjestelmä ei ole valmis ennen kuin se voidaan ottaa käyttöön luotettavasti.

Kehitysympäristö on paikka, jossa järjestelmää rakennetaan.

Deployment Engine tekee siitä toimivan ympäristön, jossa järjestelmä voidaan:

* asentaa
* käynnistää
* päivittää
* palauttaa
* ylläpitää

Deployment Engine on silta kehityksen ja todellisen käytön välillä.

---

# 2. Deployment Principle

Hyvä järjestelmä ei vain toimi kehittäjän koneella.

Sen pitää toimia:

* luotettavasti
* toistettavasti
* hallitusti
* turvallisesti

Jokaisen version pitää voida siirtyä suunnitelmasta käyttöön.

# Final Deployment Engine Definition

Deployment Engine tekee Spacemonkeysta todellisen käyttöjärjestelmän.

Ilman sitä:

järjestelmä on rakennusvaiheessa.

Sen kanssa:

järjestelmä voidaan ottaa käyttöön, kasvattaa ja ylläpitää.

Deployment Engine yhdistää:

kehityksen,

julkaisun,

ylläpidon,

ja jatkuvan parantamisen.

Se varmistaa, että jokainen uusi vaihe voi muuttua toimivaksi osaksi suurempaa kokonaisuutta.
