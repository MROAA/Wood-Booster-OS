# SPACEMONKEY GODFILE 114

# CONTEXT ENGINE CORE — THE INTELLIGENCE LAYER OF SITUATIONAL UNDERSTANDING

## 1. Context Engine Definition

Spacemonkey ymmärtää, että tieto yksin ei riitä.

Sama tieto voi tarkoittaa eri asioita eri tilanteissa.

Context Engine antaa järjestelmälle kyvyn ymmärtää:

* kuka toimii
* mitä ollaan tekemässä
* miksi asia on tärkeä
* mitä on tapahtunut aiemmin
* mitä tavoitteita on olemassa

Konteksti muuttaa tiedon merkitykselliseksi ymmärrykseksi.

---

# 2. Context Principle

# 4. User Context Layer

Spacemonkey ymmärtää käyttäjän tilanteen.

Sisältää:

* tavoitteet
* toimintatavat
* mieltymykset
* aikaisemmat keskustelut
* työskentelymallit

Tavoite:

tehdä yhteistyöstä jatkuvaa.

---

# 5. Project Context Layer

Projektit tarvitsevat oman tilanteensa.

Sisältää:

* projektin tavoite
* vaihe
* päätökset
* resurssit
* ongelmat
* historia

Esimerkiksi Wood-Booster OS:

ei ole vain koodia,

vaan jatkuvasti kehittyvä rakennusprojekti.

---

# 6. Memory Context Layer

Memory Engine tuo mukaan menneisyyden.

Se kertoo:

* mitä aiemmin tehtiin
* miksi päätettiin näin
* mitä opittiin
* mitä pitää välttää

Historia auttaa ymmärtämään nykyhetkeä.

---

# 7. Knowledge Context Layer

Knowledge Engine tuo tarvittavan tiedon.

Se yhdistää:

* dokumentit
* GODFILE:t
* tietopankin
* tekniset tiedot
* kokemukset

Oikea tieto oikeassa tilanteessa muuttuu älykkyydeksi.

---

# 8. System Context Layer

Spacemonkey tarvitsee tietoisuuden omasta tilastaan.

Se sisältää:

* aktiiviset moduulit
* agenttien tila
* saatavilla olevat työkalut
* järjestelmän rajoitteet
* virheet

---

# 9. Goal Context Layer

Jokaisella toiminnalla pitää olla tarkoitus.

Context Engine selvittää:

* mikä on tavoite
* mikä on tärkein asia juuri nyt
* mikä lopputulos halutaan saavuttaa
