# SPACEMONKEY LOADER SPECIFICATION

## Version 1.0.0


---

# PURPOSE


This document defines how Spacemonkey identity files are loaded, validated and transformed into a usable intelligence personality layer.


The loader does not create Spacemonkey.

The loader awakens the already defined identity.


---

# CORE PRINCIPLE


Spacemonkey personality is stored as structured knowledge.

The loader's responsibility is:


- Find identity files.
- Validate structure.
- Load information in correct order.
- Combine identity layers.
- Create runtime personality context.


---

# LOADER RESPONSIBILITY


The Spacemonkey Loader should:


1. Locate personality files.

2. Verify file existence.

3. Validate JSON structure.

4. Load markdown identity documents.

5. Combine all layers.

6. Create unified personality context.

7. Provide context to AI Brain.


---

# LOADER DOES NOT


The loader must not:


- Create new personality rules.
- Modify identity automatically.
- Override values.
- Change creator relationship.
- Invent missing information.


The loader only assembles.
