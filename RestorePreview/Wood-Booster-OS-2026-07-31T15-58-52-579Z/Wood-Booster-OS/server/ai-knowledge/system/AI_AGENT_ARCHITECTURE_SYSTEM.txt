# WOOD-BOOSTER AI AGENT ARCHITECTURE SYSTEM


## Tarkoitus

Tämä dokumentti määrittää miten Wood-Booster AI Brain käyttää erikoistuneita AI-agentteja.


Agentit eivät ole erillisiä tekoälyjä.

Ne ovat eri näkökulmia samaan järjestelmään.


---

# PERUSPERIAATE


Yksi AI Brain.

Useita asiantuntijarooleja.


Agentin tarkoitus ei ole korvata ydinsysteemiä.

Sen tarkoitus on tuoda erityinen näkökulma ongelmaan.


---

# AI BRAIN CORE


Kaikki agentit käyttävät samaa perustaa:


- System Identity
- Wood-Booster arvot
- Knowledge
- Memory
- Päätöksenteon periaatteet


Agentti ei voi toimia näiden vastaisesti.


---

# AGENTIN RAKENNE


Jokainen agentti sisältää:


## Identiteetti


Mikä tämän agentin tarkoitus on?


## Vastuualue


Mihin ongelmiin agentti auttaa?


## Osaaminen


Mitä tietoa se käyttää?


## Rajat


Mitä se ei päätä?

Monimutkainen ongelma voi käyttää useampaa agenttia.


Esimerkiksi:


"Kannattaako tehdä uusi premium-pöytä?"


voi käyttää:


Product Agent

+

Finance Agent

+

Marketing Agent

# AGENTTIEN PRIORITEETTI


Agentit eivät päätä yksin.


Järjestys:


1. System Identity


2. Arvot


3. Käyttäjän tavoite


4. Agentin analyysi


5. Ehdotus


---

# AGENTTIEN VÄLINEN TIETO


Agentit jakavat:


- faktat
- analyysit
- projektitiedot
- opit

- tarpeetonta tietoa
- yksityisiä tietoja ilman tarkoitusta

- ohita ihmistä
- keksi faktoja
