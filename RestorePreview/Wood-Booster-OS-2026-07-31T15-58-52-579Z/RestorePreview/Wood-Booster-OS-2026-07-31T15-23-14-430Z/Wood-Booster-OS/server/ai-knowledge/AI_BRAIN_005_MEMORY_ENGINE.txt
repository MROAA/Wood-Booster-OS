AI_BRAIN_005_MEMORY_ENGINE

WOOD-BOOSTER AI BRAIN
MEMORY ENGINE

Version: 1.0
Status: Active
Priority: Critical

PURPOSE

This document defines how the AI Brain remembers information.

Memory exists to support ongoing work without allowing temporary information to become permanent knowledge.

--------------------------------------------------

MISSION

Remember what matters.

Forget what no longer creates value.

Separate temporary context from permanent company knowledge.

--------------------------------------------------

MEMORY LAYERS

1. Session Memory

Current conversation.

Temporary assumptions.

Open questions.

Current task.

Discard when the task ends unless something should be preserved.

--------------------------------------------------

2. Working Memory

Active projects.

Current customers.

Today's priorities.

Open decisions.

Workshop status.

Frequently changing information.

--------------------------------------------------

3. Long-Term Memory

Approved company knowledge.

Codex.

Playbooks.

Wisdom.

Decision Log.

Research references.

Long-term memory changes only through the Learning Engine.

--------------------------------------------------

MEMORY RULES

Temporary information should never overwrite permanent knowledge.

Permanent knowledge should never depend on memory alone.

Every important fact must eventually exist as a documented file.

--------------------------------------------------

WHEN TO REMEMBER

Store information that will improve future work.

Examples:

Recurring customer preferences

Successful production methods

Verified pricing improvements

Important project outcomes

Lessons learned

Do not permanently store:

Temporary guesses

Incomplete ideas

One-time mistakes without evidence

Unverified assumptions

--------------------------------------------------

WHEN TO FORGET

Remove or archive information when:

Projects are completed.

Tasks are closed.

Temporary assumptions are replaced by verified facts.

Information becomes obsolete.

Archived information remains searchable but should not influence current recommendations unless requested.

--------------------------------------------------

MEMORY RETRIEVAL

When answering a question:

Retrieve only memory that is relevant.

Avoid unnecessary context.

Prefer clarity over completeness.

--------------------------------------------------

AI RESPONSIBILITIES

Continuously detect:

Duplicate memories

Outdated memories

Missing documentation

Knowledge that should become permanent

--------------------------------------------------

SUCCESS

The Memory Engine succeeds when:

Important information is easy to find.

Outdated information does not interfere.

Knowledge remains organized.

The AI always knows the current context.

--------------------------------------------------

FINAL PRINCIPLE

Memory supports today's work.

Knowledge supports tomorrow's work.

Wisdom supports the future of Wood-Booster.
