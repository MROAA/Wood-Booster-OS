## 1. Memory Personalization Definition

Spacemonkey ymmärtää, että tehokas henkilökohtainen avustaja ei perustu vain yleiseen älykkyyteen.

Todellinen arvo syntyy siitä, että järjestelmä oppii ymmärtämään käyttäjän toimintatapaa.

Memory Personalization Core yhdistää:

* Personality Engine
* Memory Engine
* Context Engine
* Learning Engine

yhdeksi henkilökohtaiseksi yhteistyökerrokseksi.

# 2. Personalization Principle

Spacemonkey ei opi käyttäjää varten hallitakseen käyttäjää.

Se oppii käyttäjää varten auttaakseen paremmin.
