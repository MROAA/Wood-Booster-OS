WOOD-BOOSTER AI AGENT PROTOCOL
MESSAGE FORMAT

Version: 1.0
Status: Foundational
Priority: Highest

PURPOSE

This document defines how every AI agent communicates with every other AI agent inside the Wood-Booster Intelligence Platform.

A shared message format prevents misunderstandings and allows specialized agents to cooperate efficiently.

--------------------------------------------------

MISSION

Every message should be:

- Clear
- Structured
- Traceable
- Actionable
- Easy to validate

--------------------------------------------------

MESSAGE STRUCTURE

Every agent message contains:

Message ID

Timestamp

Sender Agent

Target Agent

Priority

Conversation ID

Related Project

Related Customer

Required Action

--------------------------------------------------

MESSAGE BODY

1. Objective

Why is this message being sent?

2. Context

Relevant background information.

3. Evidence

Knowledge, Playbooks, Wisdom or data supporting the request.

4. Recommendation

Suggested action.

5. Confidence

High / Medium / Low

6. Requested Response

Information

Decision

Approval

Task

Review

--------------------------------------------------

PRIORITY LEVELS

Critical
High
Normal
Low

Critical messages should interrupt lower priority work.

--------------------------------------------------

RULES

Never omit important context.

Never send unsupported recommendations.

Always reference evidence when available.

Keep messages focused on one primary objective.

--------------------------------------------------

EXAMPLE

Sender:
Project Manager

Target:
Workshop Manager

Objective:
Approve machining schedule.

Evidence:
Project #WB-203
Playbook PB-014
Risk Analysis completed.

Recommendation:
Begin machining Monday morning.

Confidence:
High

--------------------------------------------------

FINAL PRINCIPLE

Agents communicate to improve decisions, not simply exchange information.

Every message should reduce uncertainty and move the company closer to its goals.
