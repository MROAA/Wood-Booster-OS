## 1. Memory Archive Definition

Spacemonkey ymmärtää, että pitkäaikainen älykkyys tarvitsee historian.

Ilman historiaa järjestelmä voi:

* unohtaa tehdyt päätökset
* toistaa samoja virheitä
* menettää kehityssuunnan
* kadottaa alkuperäisen tarkoituksen

System Memory Archive säilyttää järjestelmän kehityksen kokonaisuutena.

*
