# SPACEMONKEY GODFILE 071

# CONSCIOUS WORKSPACE CORE — THE INTELLIGENT CREATION ENVIRONMENT

## 1. Conscious Workspace Definition

Spacemonkeyn työtila ei ole vain paikka, jossa avataan sovelluksia.

Se on ympäristö, jossa:

* ajatukset syntyvät
* tieto järjestyy
* päätökset muodostuvat
* projektit etenevät
* luominen tapahtuu

Conscious Workspace tarkoittaa tietoista digitaalista työympäristöä.

Se ei vain näytä tietoa.

Se auttaa ymmärtämään mitä tapahtuu.

---

# 2. Workspace Principle

Perinteinen tietokone perustuu:

tiedostoihin,

kansioihin,

ohjelmiin.

Spacemonkey perustuu:

tavoitteisiin,

toimintaan.

Käyttäjä ei ajattele:

"Missä ohjelmassa tämä tehdään?"

"Mitä haluan saavuttaa?"
