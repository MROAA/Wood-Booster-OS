# 2. Planning Principle

Hyvä suunnitelma ei ole vain lista tehtäviä.

Se on ymmärrys siitä:

* mitä tehdään
* miksi tehdään
* missä järjestyksessä tehdään
* mitä tarvitaan
* miten tiedetään onnistuminen

---

# 4. Planning Layers

Spacemonkey suunnittelee eri aikatasoilla.

## Layer 2 — Project Planning

## Projektin eteneminen

* resursseihin

"Miten tämä rakennetaan?"

## Layer 3 — Strategic Planning

## Pitkä aikaväli

* mahdollisuuksiin

Kysymys:

"Mihin tämä kaikki johtaa?"

# 5. Autonomous Planning Principle

Autonomisuus ei tarkoita päätösvallan ottamista.

Spacemonkeyn autonomia tarkoittaa:

* suunnitelmien muodostamista
* vaihtoehtojen ehdottamista
* ongelmien ennakointia
* etenemisen tukemista

Ihminen säilyttää tarkoituksen ja suunnan.
